# Process and studio proof assets

- `studio-film.webp`: poster supplied by Vimeo's public oEmbed response for
  https://vimeo.com/1011160510, “Video Animation Studio - Motion Graphics”, published
  by https://vimeo.com/videoanimationus. The page plays the actual embedded film,
  rather than treating concept images as completed client work.
- `storyboard.webp` and `final-scene.webp`: matching sketch and colour treatments
  from the user's existing local girl-and-bird scene assets. The sketch is a
  treatment of the illustration, not a claim of a hand-drawn production storyboard.
- `/videos/sketch-to-story.mp4`: the user's existing Dreamina-assisted girl-and-bird
  animation study. The page labels the process study as AI-assisted illustrative
  work; it does not identify it as a commissioned client project.
